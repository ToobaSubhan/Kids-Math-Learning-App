# Enjoy Maths: Kids Math Game 🦉

**Enjoy Maths** is a gamified educational Android application designed to help children aged 6–12 master basic arithmetic operations (+, −, ×, ÷) through interactive gameplay and adaptive learning.

## 🌟 Key Features

- **🧠 Adaptive Learning Engine**: The app identifies "Weak Spots" by tracking incorrect answers and intelligently reintroduces those specific problems to reinforce learning.
- **📅 Daily Challenges**: A unique daily math mission to help build a consistent learning habit, complete with a streak system and a progress calendar.
- **💡 Smart Hint System**: Instead of just giving the answer, the app provides educational "scaffolding" hints (e.g., repeated addition for multiplication) to help children understand the logic.
- **📊 Weakness Reports**: A detailed dashboard where kids and parents can see which specific numbers or operations need more practice.
- **🎨 Dynamic Themes**: The interface changes its colors and symbols based on the operation being practiced (e.g., Green for Addition, Blue for Subtraction).
- **🏆 Motivational Feedback**: High-score tracking, streak badges, and animated rewards like confetti to keep kids engaged.

## 🛠️ Tech Stack

- **Language**: 100% Kotlin
- **Database**: SQLite (Local persistence for scores, sessions, and analytics)
- **UI**: XML with Material Design 3 components
- **Architecture**: Modular Activity-based architecture
- **Animations**: Custom Canvas API for star backgrounds and Property Animators for UI transitions.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ToobaSubhan/Kids-Math-Learning-App.git
   ```
2. **Open in Android Studio**:
   - Go to `File > Open` and select the project folder.
3. **Build & Run**:
   - Sync the Gradle files.
   - Run the project on an emulator or a physical device (Minimum SDK 24).
